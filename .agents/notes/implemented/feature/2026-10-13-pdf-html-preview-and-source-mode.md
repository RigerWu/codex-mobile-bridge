# Agent Note: PDF 阅读与隔离 HTML 预览及源码切换

Status: implemented

## Problem

工作台的文本预览最多读取 512 KiB，PDF 走普通二进制提示，HTML 只能看源码。用户需要在浏览器和手机工作台阅读 PDF，也需要运行自包含 HTML 中的内联交互，同时保留原文源码视图。PDF 不应一次性塞入文本预览响应；HTML 文件中的脚本不能获得网关页面权限。

## Decision

工作台按 `.pdf` 后缀先调用既有会话的 `workspace/download?info=1`，用服务端核验的文件大小和 `clickDownloadMiB` 预检。在线阅读另限 20 MiB，不改变 512 KiB 文本预览门槛；合格文件交给 `BridgePdfPreview.create({url, info})`，`load()` 使用同一带鉴权的下载 URL 与既有 Range 响应，并附 `preview=1`。网关对每次请求执行 `min(20 MiB, clickDownloadMiB)` 的实际文件限额，拒绝与 `explicit/archive` 混用；防止 `info` 后文件变大绕过预算，普通下载行为保持不变。PDF.js 固定为 5.6.205 的本地 legacy module 与同版本 worker、CMap、标准字体，Apache-2.0 许可及字体许可随资源分发。PDF 各页按自身原始宽度适配阅读容器，100% 时横竖混排页都完整显示；粗触控输入下采用原生单指滚动和双指缩放，宽屏保留可聚焦的翻页、缩放按钮和键盘控制。双指手势期间仅作临时视觉缩放，结束后以触点为锚点一次性重排及重渲染。ResizeObserver 只预约下一帧布局，避免在通知期间写入尺寸；宽度改变时保留阅读页与位置，隐藏容器的零尺寸回调不改变阅读状态。工作台切换标签时保存并恢复 PDF 内部阅读区的纵横滚动位置。连续阅读只加载可见页，少于三页时补相邻页；预算允许时额外保留至多两张邻近已绘制页面，远离阅读区的页面取消渲染并释放画布和文本层。缩放或容器宽度改变时保留完成的画布，以 CSS 尺寸即时适配；新画布在离屏绘制完成后才替换旧画布，过期绘制取消，不显示未完成的缓冲区。同一时刻只允许一个替换画布，每页最多约 4 MP，已提交画布按实际像素保持合计不超过约 12 MP，重绘瞬时合计不超过约 16 MP；降低像素占用的替换优先，避免多页出现或邻页回看突破预算。多于三页同时可见时，只保留视口中心最近三页的可选文字层，其余页仍呈现画布；文字层选择变化独立于像素绘制。未知页先用首页尺寸占位，邻近加载得到真实尺寸后补偿滚动锚点，避免混合尺寸页跳读。文字流通过 `streamTextContent().getReader()` 逐块收集，避免 iOS 18.2 缺少 ReadableStream 异步迭代器而失败；仅文字层提取或排版失败时保留已绘制的画布，画布渲染失败仍报告错误。关闭标签或重置工作台销毁加载任务。`isEvalSupported:false`、`enableXfa:false`、`useWasm:false`，不装 PDF 脚本、交互表单或 annotation action 层。加密、格式损坏、限额或读取失败均给出消息，文件头部保留下载入口。

HTML 使用 `BridgeHtmlPreview.create({text}) -> {element, dispose()}`。工作台提供“预览／源代码”按钮；源码复用 `BridgeSourceView.create({name, text})`，复制从原始文本取值。切到源码或关闭标签即销毁 HTML iframe。首版只覆盖文本预览门槛内的自包含 HTML，不扩展多文件站点或外部依赖。

HTML 执行环境是鉴权后返回的固定 `/html-preview-shell`，与用户正文分离。壳的 CSP 使用 `sandbox allow-scripts`，允许内联脚本与样式，默认禁资源，并禁止连接、表单和嵌套框架；主页面 `frame-src` 仅指定该壳路径。iframe 只授 `allow-scripts`，不授同源；壳发 ready 消息后，父页面核验 source/origin，按壳文档实例标识传入不超过 512 KiB 的固定 UTF-8 文本；壳只接收一次匹配该标识的内容。文件标签卸载后重新挂载会产生新壳文档并重新握手，避免标签返回后空白。标识仅用于文档生命周期去重，不作为权限凭证。握手脚本使用局部作用域，避免 `document.open/write` 后保留的全局词法变量与用户 HTML 同名。iOS/Android 原生导航仅允许预览子帧进入固定壳，后续导航和高权限对话框被拒。壳不读取磁盘路径或任意 URL。

`web/assets.json`、固定公开 URL 白名单和 `scripts/gateway-resources.json` 同步纳入 PDF.js、HTML 壳、脚本与许可；CMap/字体仅由限定文件名的静态路由公开。SSH 注入的工作区 Python 源模块保持独立，不依赖页面脚本。

## Existing-note audit

已检索本仓库活跃笔记的 PDF、HTML 和预览关键词。本项吸收已批准的同名本地提案；[只读源码视图](2026-10-13-source-code-view.md)持有高亮、行号和复制原文约定，本笔记只记录 HTML 对其复用。鹈鹕测试中不可信 HTML 产物隔离属于相邻场景，不扩展到本项的模型或智测历史。

## Alternatives considered

- 保持单页加翻页按钮最省渲染资源，但手机阅读必须反复点击且占用高度；改为仅可见页连续阅读，保留宽屏按钮。

- 缓存整份 PDF 可以减少回看时的重绘，但内存随页数增长；采用总像素预算内的有限邻页缓存。
- 浏览器原生 PDF 嵌入依赖少，但 WebView 控件和文本选择体验不一致，关闭后的加载任务也难以统一控制；改用本地 PDF.js 页面渲染。
- 将 PDF 经现有 `preview` 响应转 base64 实现简单，但突破 512 KiB 门槛、复制整文件并放大内存成本；使用已有受限 Range 下载路径。
- 直接把 HTML 插入工作台 DOM 能原样执行交互，但它会继承网关页面权限；选择独立壳和受限 iframe。
- 只呈现静态 HTML 更容易隔离，但不能满足已确认的内联交互范围；允许壳内脚本并限制网络、导航和同源能力。

## Consequences

原先缩放会先销毁旧画布，并把尚未完成的非透明新画布直接挂到页面，引起空白或黑屏闪烁。现在缩放期间短暂沿用旧画面，可能稍显模糊，完成后替换为清晰画面；首次跳到尚未绘制的远页仍需等待。画布像素缓冲的瞬时上限约为 64 MiB，不包含 PDF 文档、字体、文字层等内存，也不构成多个文件标签的全局预算。

普通、带文本层或扫描 PDF 可连续阅读；文档超过下载策略或 20 MiB 时需要下载后打开，扫描件不承诺 OCR。PDF.js 的本地资源增加网关体积，但离线和 SSH 页面不依赖 CDN。全屏切换保留 HTML 交互状态；切换文件标签后返回会重新加载该 HTML，不承诺跨标签保留脚本内存。HTML 内联交互仅在隔离壳内运行，相对文件、外部 CDN、后端 API、表单提交和弹窗不属于首版支持范围。

Node 定向测试覆盖大小预检、离屏渲染取消、混合尺寸和高视口可见页的画布预算、隐藏后恢复的阅读锚点、偏离中心的双指缩放、观察回调延后布局及关闭时取消、工作台 info 路由及 HTML 源码切换；资源布局测试检查所有白名单与清单路径。HTML 合成 HTTP/relay 鉴权和 CSP 检查由同批安全测试覆盖。主审在真实 Chromium 验证了中文 PDF 的渲染与文本选择、翻页与缩放、扫描图页以及损坏/超限提示；HTML 的内联交互和源码切换通过，cookie、storage、父页面与宿主桥访问被拒，网络、表单与自导航未到达合成服务器。合成回归覆盖 PDF 在 info 后增长及 SSH/relay 参数路径。Android 构建和签名验证通过；只读 Android 模拟器实际单指滑动通过 30 页混合尺寸 PDF 的 1→3 页阅读，并验证全屏进出及标签返回保持页内位置；HTML 标签返回仍可执行内联按钮。模拟器命令未提供双指注入，因此原生 pinch 未验；iOS 18.2 Simulator 实际验证连接、源码换行、中文 PDF、混合尺寸逐页适配和全屏、HTML 内联交互与子帧跳顶层隔离。原生首次导航用一次性的预期 URL、WKWebView 身份和代际约束放行，预览子帧不能借此导航主页面。模拟器触摸注入未能可靠验证 iOS 单指/双指手势；Chromium CDP 双指触摸验证文档 100%→200%、页面整体比例保持 1，真实设备手感仍需用户实测。多个隐藏 PDF 标签保留文档状态，关闭或重置才释放；文件头把描述放左、下载与预览/复制操作放右；320px 英文布局用带完整无障碍名称的图标压缩下载/全屏。全屏入口紧邻下载。同一预览内容进入全屏时在原 tab.body 上切换 fixed 布局并使外层界面 inert，退出时恢复原位；PDF 与 HTML 预览实例不重建，ResizeObserver 处理尺寸变化。HTML 壳经已核验的消息通道可请求退出全屏，父页面只把它映射为关闭当前全屏而不授予其它操作；不承诺全文件标签的统一内存配额。官方依据：[PDF.js API](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html)、[PDF.js Getting Started](https://mozilla.github.io/pdf.js/getting_started/)；Context7 月配额耗尽后使用官方文档。

PDF 闪烁回归：新增延迟绘制、连续取消、原比例回退后恢复文字、邻页复用、文字层独立更新以及逐次提交像素预算测试，PDF 定向 20/20 通过；全量 Node 603 项中 602 通过、1 项跳过。主审在前台 Chromium 的 6 倍 CPU 限速下快速连续缩放，修复前短采样 4 帧中 2 帧没有可见画布，修复后短采样 7 帧中未发现空白或黑色画布；这是机制验证，不是帧率基准或任意文档零闪烁保证。最终代码的相邻翻页返回复用了原画布，总画布像素仍在预算内。iOS 18.2 WKWebView 复验中文及混合尺寸 PDF、全屏进出通过；本轮未新增原生双指手势验证，实机手感仍由用户确认。
