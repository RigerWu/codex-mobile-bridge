# Agent Note: Claude 与 DSH 列表状态只提示需关注的结果

Status: implemented

## Problem

客户端列表在每次轮询成功后显示“已连接桌面”，并在已有缓存会话时反复显示“正在读取聊天”。这两种正常状态占用列表空间，却没有给用户新的行动信息。

## Decision

有会话的正常列表读取完成后清空列表状态；已有缓存会话时，重新读取不显示等待文案。首次无缓存读取仍显示等待状态；空列表显示无聊天提示。连接初始化、断开、失败和可操作的重试提示继续由现有连接状态流程展示。

## Alternatives considered

保留“已连接桌面”并只减小字号可以继续提供连接确认，但它仍在每次成功轮询后常驻，无法让真正的异常更突出。

## Consequences

列表更安静，空列表和连接异常仍有明确解释。连接成功本身不再是列表中的持续文案；连接状态仍由客户端管理和会话详情各自展示。桌面会话 UI 回归覆盖正常、空列表、失败与初始化状态。
