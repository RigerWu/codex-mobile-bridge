# Agent Note: 文件传输设置在可见且已登录时读取

Status: implemented

## Problem

文件传输设置挂载时立即读取网关，登录前会把“请登录”留在外观面板。后续成功读取只更新输入值，没有清除这条旧错误。桌面高级面板也会在隐藏时提前请求设置。

## Decision

文件传输设置仅在面板可见、页面未隐藏且调用方已就绪时读取。Web 调用方通过已显示的登录后应用判定就绪；桌面本地调用方显式提供就绪条件。面板揭示、窗口聚焦及登录完成事件触发读取，不增加轮询。成功读取清除旧读取错误，正在编辑的值不被覆盖。

## Alternatives considered

在登录时自动重试而保留挂载时请求，触发次数更少，但仍会产生一次无意义的未授权请求，也不能覆盖桌面隐藏面板的场景。

## Consequences

未打开的设置面板不再触发读取。错误只在用户实际查看设置时出现，并会随下一次成功读取消失。独立保存按钮仍更新 clickDownloadMiB，不进入网关通用设置草稿。桌面设置测试验证隐藏挂载、揭示读取与独立保存。
